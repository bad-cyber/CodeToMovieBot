# 🎬 CodeToMovieBot

Telegram бот для управления коллекцией фильмов с возможностью добавления, редактирования и просмотра информации о фильмах.

```
CodeToMovieBot/
├── config/                     # Конфигурационные файлы
│   ├── __init__.py
│   ├── config.py              # Основные настройки бота
│   ├── admins.txt             # Список администраторов
│   └── beta.txt               # Список бэта пользователей
│
├── database/                   # База данных и её обработчики
│   ├── __init__.py

│   └── sqlitebot.db           # SQLite база данных
│
├── handlers/                   # Обработчики команд
│   ├── __init__.py
│   ├── admin_handler.py       # Админ-команды
│   └── basic_handler.py       # Базовые команды
│
├── services/                   # Сервисные модули
│   ├── __init__.py
│   ├── film_tools/            # Инструменты для работы с фильмами
│   │   ├── __init__.py
│   │   ├── film_builder.py    # Построение сообщений
│   │   ├── film_scraper.py    # Парсинг информации
│   │   └── helper.py          # Вспомогательные функции
│   └── check_sub.py           # Проверка подписки

├── dispatcher.py              # Диспетчер команд
```

## 🚀 Возможности

- Добавление фильмов через ссылки film.ru(Adm.)
- Просмотр информации о фильмах по коду
- Случайный выбор фильма
- Редактирование информации о фильмах(Adm.)
- Удаление фильмов(Adm.)
- Администраторский доступ(Adm.)
- Проверка подписки на канал

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/bad-cyber/CodeToMovieBot.git
cd CodeToMovieBot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл config/config.py и настройте параметры бота:
```python
BOT_TOKEN = "ваш_токен_бота"
CHANNEL_ID = "ид_канала_для_проверки_подписки"
```

4. Запустите бота:
```bash
python main.py
```
4.1. Размещение бота на сервере:
 - Переносите директорию бота в желаемую директорию на сервер.
 - выполняете: 
```bash
cd CodeToMovieBot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
- затем, если вы также пользуетесь сервисом sprintbox.ru , то далее выполняем это:
```bash
tmux
python main.py
```
